<details>
<summary><b>🌟 Overview</b></summary>
<br>

The **Online Complaint Box** is a comprehensive web application designed to bridge the gap between citizens and authorities. Built with modern web technologies, it offers a seamless experience for users to submit, track, and manage complaints online. The platform emphasizes transparency, speed, and accessibility with multi-language support.

</details>

<details>
<summary><b>✨ Key Features</b></summary>
<br>

- 🌍 **Multi-Language Support**: Accessible to a wider audience with built-in support for multiple languages (English, Sinhala, Tamil) with responsive typography logic.
- 📱 **WhatsApp Integration**: Instant notifications and updates routed directly via WhatsApp for lightning-fast communication.
- 🎨 **Modern UI/UX**: A stunning, fully responsive interface utilizing glassmorphism, premium 3D illustrations, and smooth micro-animations.
- ⚡ **Fast Processing**: Streamlined complaint submission form designed to take less than a minute to complete.
- 🔒 **Secure & Confidential**: User data and sensitive complaints are handled with top-tier security and privacy measures.
- 📊 **Track Progress**: Users can easily track the status of their complaints in real-time.
- 📝 **Google Sheets Integration**: Every submitted complaint is automatically and instantly synced to a secure Google Spreadsheet for administrative tracking and record-keeping.

</details>

<details>
<summary><b>🚀 Getting Started</b></summary>
<br>

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

- Node.js 18.0 or higher
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ShajahanImdaad53/online-complaint-box.git
   cd online-complaint-box
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open the application:**
   Navigate to [http://localhost:3000](http://localhost:3000) in your web browser.

</details>

<details>
<summary><b>💡 How It Works</b></summary>
<br>

1. **Create Account**: Users sign up securely on the platform.
2. **File Complaint**: Users fill out a dynamic form with details, photos, and location.
3. **Track Progress**: The system processes the complaint and provides live status updates.
4. **Get Resolution**: Once resolved, the user receives an outcome report and a WhatsApp notification.

</details>
